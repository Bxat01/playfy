# Security Policy

## Supported versions

Security fixes are made against the latest code on the `main` branch. Older builds may not receive updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Use GitHub's private vulnerability reporting for this repository when available, or contact the maintainer privately through [GitHub](https://github.com/Bxat01).

Include the affected version or commit, the platform, steps to reproduce, and the likely impact. Do not include passwords, access tokens, or other people's private data in a report.

The maintainer will review reports and coordinate any fix or disclosure. Response and resolution times are not guaranteed.
