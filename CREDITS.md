## Base project

Playfy began from the public **Discord Quest Completer** project by **Mark Terence Tiglao** (markterence), released under the MIT License:

- https://github.com/markterence/discord-quest-completer

The current application is a substantial rewrite rather than a rebrand of that project. The visible named session process, session card, queue lifecycle, detection flow, frontend, settings and visual identity were rebuilt for Playfy. The original MIT notice is preserved in [LICENSE](LICENSE).
